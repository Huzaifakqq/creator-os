Session Objective

Resolve ACEScc DaVinci highlight clipping when applying third-party camera vendor creative LUTs. Maintain full 16-bit float dynamic range roll-off from Alexa 35 ARRI LogC4 without gamut shearing.

01 Diagnostic Finding & Root Cause

Client’s project was set to ACEScc AP1 timeline working space, but the creative vendor LUT was authored in standard Rec.709 Gamma 2.4. Applying this LUT directly inside an ACEScc timeline crushes values > 1.0 down to hard 100 IRE clipping point.

  • Node 05: Film Grain & Halation: Applied in Log space before final Rec.709 display delivery.
