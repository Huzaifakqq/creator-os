Quick tip: When connecting the Webhook endpoint to Inngest with Creator OS SDK v2.4, remember to verify the HMAC SHA-256 header before dispatch.

webhook-handler.ts verified 
import { verifySignature } from "@creatoros/sdk";

const isValid = verifySignature({
  payload,
  sig: headers["x-hub-signature-256"]
});
